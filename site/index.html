Let a swarm of cursors build your UI, live.

Wrap any section in <cursor-swarm> and a crowd of multiplayer cursors draws the boxes, types the text and drops in the images, right in front of your visitors.

Install

      
Works wherever HTML works.

      
It's a standard custom element, so plain HTML, React, Next.js, Vue, Svelte, Astro, Webflow and WordPress all work. There's also a small typed React wrapper.

      

        

          
          
          
          
          
        

        

      

    

  


  
    

      

        
Why

        
Small, polite, and a little bit magic.

        
This section builds as you scroll to it. That's the default scope="viewport": the cursors keep pace with the reader.

        

          
⌁
Zero dependencies
One small ES module. Load it from a CDN with a single script tag.

          
⬚
Reads your real DOM
No config needed. Boxes are drawn, text is typed line by line and images wipe in, all using your own CSS.

          
↯
Keeps up with scrolling
Cursors speed up when there's a backlog, so fast scrollers never wait long.

          
♪
Optional sound
Soft clicks and keystrokes synthesized with Web Audio. No audio files, and off by default.

          
◎
Accessible by default
Respects prefers-reduced-motion, never blocks clicks, and leaves your markup untouched.

          
⚛
Framework friendly
Typed React wrapper and SSR safe. Events and methods let you control playback.

        

      

    

  

  

    

      
API

      
Attributes, methods, events.

      

        
AttributeDefaultDescription

        
          
cursors5How many cursors join in (1–24).

          
speed1Build speed multiplier.

          
triggervisiblevisible starts when scrolled into view, load starts immediately, and manual waits for play().

          
scopeviewportviewport builds what's on screen as you scroll, and all builds everything right away.

          
linger2500Milliseconds the cursors flock around your pointer before leaving. Use 0 to leave right away or infinite to stay.

          
soundoffTurns on synthesized clicks and typing sounds.

          
volume0.4Sound volume, from 0 to 1.

          
namesAva, Kai, …Comma-separated cursor names.

          
colors8 colorsComma-separated CSS colors.

          
hide-labelsoffHides the name tags.

          
ignore-reduced-motionoffAnimates even when the user prefers reduced motion.

        
      

      
Per-element hints

      

        
AttributeDescription

        
          
data-swarm="text | box | block | media"Forces how an element is built: typed, drawn as a container, drawn as one block, or wiped in.

          
data-swarm="skip"Doesn't animate this element itself, but still animates its children.

          
data-swarm-ignoreLeaves this element and everything inside it untouched and always visible.

        
      

      
Methods & events

      

        
NameDescription

        
          
play()Starts building. Use it with trigger="manual".

          
replay()Hides everything and builds it again.

          
finish()Skips to the end.

          
reset()Reveals everything, removes the cursors and goes back to idle.

          
swarmstart · swarmcomplete · swarmendFired when building starts, when the last element is built, and when the cursors have left.
