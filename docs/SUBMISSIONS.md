# Where to submit cursor-swarm

Ready-to-paste entries for free, open-source UI directories. Submit one per PR, and read each list's CONTRIBUTING file first.

> Publish to npm (`npm publish`) before submitting, so the install instructions work for reviewers.

## 1. awesome-shadcn-ui (≈20k ★)

Accepts installable shadcn registries. The easiest route is the form at [awesomeshadcn.dev](https://awesomeshadcn.dev/), which opens the PR for you.

- **Name:** cursor-swarm
- **URL:** https://ricco.codes/Swarm-Cursor-component/
- **Description:** A crowd of multiplayer cursors builds your UI live. Install with `npx shadcn@latest add https://ricco.codes/Swarm-Cursor-component/r/cursor-swarm.json`. Free, MIT.

## 4. shadcn registry directory

shadcn/ui lists community registries in `apps/v4/app/r/registries.json`. Once the project has some traction, open a PR there following the repo's registry guidelines. The registry index is already served at `https://ricco.codes/Swarm-Cursor-component/r/registry.json`.
